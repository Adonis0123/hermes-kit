# Glossary / 术语表

Terms used across hermes-kit docs. Each entry: English, then 中文.

| Term | English | 中文 |
| --- | --- | --- |
| upstream | [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent), the official Hermes Agent repo. | Hermes Agent 官方仓库。 |
| fork | [Adonis0123/hermes-agent](https://github.com/Adonis0123/hermes-agent): upstream plus the overlay. | 上游加 overlay 的 Hermes 分叉仓库。 |
| overlay | The small stack of patch commits the fork keeps on top of an upstream release, re-applied by rebase. | fork 叠在上游发版之上的一小串补丁提交，每次用 rebase 重新叠加。 |
| source repo | A private repo where content is written and used daily; the single source of truth. | 日常编写和使用内容的私有仓库，是唯一事实来源。 |
| public repo | A repo such as hermes-kit or adonis-skills whose content is generated by export from a source repo. | 内容由源仓库导出生成的公开仓库，如 hermes-kit、adonis-skills。 |
| export allowlist | The list of paths the export script may copy from a source repo; anything not listed stays private. | 导出脚本可以从源仓库复制的路径清单，未列出的都保持私有。 |
| local-* file | A file such as `references/local-team.md` holding personal or company specifics; never exported. | 存放个人或公司细节的文件，如 `references/local-team.md`，永不导出。 |
| tap | A GitHub repo added to Hermes as a skill source with `hermes skills tap add owner/repo`. | 用 `hermes skills tap add owner/repo` 加进 Hermes 的技能源仓库。 |
| marketplace | A Claude Code plugin catalog defined by `.claude-plugin/marketplace.json`, added with `/plugin marketplace add`. | 由 `.claude-plugin/marketplace.json` 定义、用 `/plugin marketplace add` 添加的 Claude Code 插件目录。 |
