# 「按推荐来」= 今早复盘编号表

课例 2026-08-19/20：长会话里说「按照你推荐的来 / 按照推荐来」时，做成了**本会话自拟可复用项**，不是 09:20 复盘的 1/2/3/4。

## 确认语（同义）

`确认，按你推荐的来` / `按推荐来` / `按推荐的来` / **`按照推荐来`** / **`按照推荐的来`** / **`按照推荐的来吧`** / **`按照你推荐的来`** / **`全部优化`**

全部 = 做 **今早** `~/.hermes/cron/output/<job_id>/` 最新 `*.md` → `## Response` → `### 可以改进` 的编号表。

**不是**当前长会话里自己列的可复用项，也不是更早一天的复盘表。

## 裸数字不当确认（硬·2026-08-25）

其他会话里的 `1、3、4` / `1 2`（无「确认」二字）**不是**复盘确认，即使时间紧挨 09:20。课例：09:25「1、3、4」做成了卡片开关，8/24 复盘 1–4 整日未动。

只认：

1. 带「确认」：`确认 1,3` / `确认 1`
2. **`只优化 N`** / `只优化 1,3` 等价 `确认 N`：只做**磁盘最新**复盘表第 N 条；不是升版后「值得关注」编号、不是长会话自拟清单
3. 复盘会话本身的跟进
4. 「按推荐来 / 全部优化」（= 今早整张表）

## 取终稿（执行前必做）

0. **第一件事只读磁盘**（硬·2026-09-09；补·2026-09-11）：`ls -t ~/.hermes/cron/output/<job_id>/*.md | head -1`，记下文件日期，读完 `### 可以改进` **再动手**。压缩窗口后：**只认磁盘最新表 + 压缩后那条用户原文**。禁止执行摘要里的旧确认 / 「按照推荐来」 / 「锁屏」。课例 2026-09-08：先按旧「确认 1,2」改了一轮。课例 2026-09-10：「只优化 2」压缩后先回放 9/9 表和晚上「锁屏」。
1. `session_search`：`昨日工作复盘` / `cron_<job_id>_*` 当天 session 最后一条 assistant
2. FTS 找不到 / 只命中旧会话 / 标题不是当天 / **和磁盘最新文件日期不一致** → 以磁盘为准，读 `### 可以改进`
3. 对不上就停问；禁止凭长会话或记忆里的旧编号表顶替
